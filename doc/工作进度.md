### 背景

对旧设计（super/flex/normal 三档、最高权限计划任务、合盖防护、强制亮屏、pi/Claude Code 钩子）逐条盘问后，用户确认新契约。旧 C2 审查（`doc/reviews-C2/`）针对旧契约代码，其结论已被本次重定取代，报告仅作历史记录。

### 新契约（逐条经用户确认）

1. 命令只留 `on` / `off` / `status`；super/flex/normal、arm/disarm、install-task/uninstall-task、install-hook、restore、bootcheck、`--sleep-now` 全部移除。
2. 只在**插电**时挡系统空闲睡眠（`ES_CONTINUOUS | ES_SYSTEM_REQUIRED`）；拔电立即放开，插回自动续挡；电源状态读不到 → 不挡并如实报错。
3. 屏幕**不强制常亮**（不设 `ES_DISPLAY_REQUIRED`），按 Windows 显示超时自行变黑（本机插电 300s / 电池 180s，实测确认）。
4. 合盖、电源键、电源计划（`powercfg`）**从不修改**；不注册计划任务；不写 settings.json 钩子；全程无 UAC。
5. 不跨重启保留；全机单开关，后跑的算数，`off` 一定放开。
6. 旧版残留清理：`off` / `uninstall.ps1` 检测到 `keep-awake-strong` / `keep-awake-bootcheck` 任务、`power-backup.json`、`strong*` 文件、旧钩子时，一次性恢复电源计划并删除（仅此场景弹一次 UAC）；失败如实报告。
7. 屏幕到点再黑，不强制立刻关屏。
8. 用电池也开着 `on` 时不硬撑（用户否决「电池也醒着」）。
